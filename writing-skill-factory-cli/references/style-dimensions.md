## 标点偏好分析

- **逗号密度**：每句平均逗号数
- **句号密度**：每段平均句号数
- **分号使用**：频率、场景
- **破折号使用**：频率、功能（解释 / 转折 / 延长）
- **括号使用**：圆括号 / 方括号 / 书名号内的补充说明
- **引号使用**：直接引用 vs 强调 vs 反讽
- **省略号使用**：频率、情感功能
- **感叹号与问号**：频率、分布位置

## 分块习惯

- 文章整体分块模式（如：引子 → 背景 → 核心 → 延伸 → 收尾）
- 每块的典型字数范围
- 块与块之间的过渡方式

## 段落配方

记录高频出现的段落类型及其内部结构：

```
配方名称：观点-例证-回扣
结构：[观点句] + [案例/数据] + [回扣观点的收束句]
出现频率：高频
典型长度：3-5 句
```

## 叙述方法

- 顺叙 / 倒叙 / 插叙 / 多线并行
- 视角切换模式
- 时间标记方式

## 内容推进方式

- 问题驱动（提出疑问 → 展开分析 → 给出判断）
- 案例驱动（具体情境 → 抽象提炼 → 普适结论）
- 数据驱动（数据呈现 → 解读 →  implications）
- 观点驱动（核心观点 → 分层论证 → 强化）
